# AGENTS.md — Kernel Soluciones (Astro 7 + Tailwind 4)

Static multilingual marketing site. Node `>=22.12.0`. No monorepo, no CI, no project tests.

## Source of truth: config.toml codegen

- Edit `src/config/config.toml`. Never edit `.astro/config.generated.json` — it is regenerated by `scripts/toml-watcher.mjs` (`node scripts/toml-watcher.mjs`, `--watch` in dev).
- `npm run dev` / `npm run build` already run `toml:watch` first; if you edit TOML outside those scripts, re-run the watcher once.
- Restart dev server after changing `site.trailingSlash`, `settings.*Folder`, or `settings.multilingual.*` (read at import time in `astro.config.mjs` / `src/lib/utils/i18nUtils.ts`).
- `astro.config.mjs` reads `site.baseUrl`/`trailingSlash`, i18n routing (`prefixDefaultLocale = showDefaultLangInUrl`), and `seo.sitemap.enable`.

## Commands

- `npm run dev` — dev at `localhost:4321` (with TOML watcher)
- `npm run build` — `toml:watch && astro build && remove-draft-from-sitemap` (post-processes `dist/sitemap-*.xml`: drops `draft`/`excludeFromSitemap`, `-index` pages, `widgets`/`sections`/`author` folders)
- `npm run preview` — build + `astro preview`
- `npm run astro-check` — typecheck (`astro check`)
- `npm run format` — `prettier -w ./src` (plugins: astro, toml, tailwindcss; 2-space, LF)
- Tests: `npm test` runs `jest --watch` and hangs — use `npx cross-env TS_NODE_PROJECT=./tsconfig.jest.json jest --watchAll=false` instead. There are currently no repo tests (`jest.config.ts` + `tsconfig.jest.json` exist, `src/**/*.test.*` empty).
- Deploy: Netlify (`netlify.toml`, `yarn build`), Vercel (`vercel.sh` passes `--site` from `VERCEL_PROJECT_PRODUCTION_URL`), Cloudflare (`npm run deploy:cf` → `wrangler pages deploy ./dist`).

## Path aliases (non-standard — will guess wrong)

From `tsconfig.json` (`@/*` is NOT `src/components/*`):

- `@/*` → `src/*`
- `@/components/*` → `src/layouts/components/*`
- `@/shortcodes/*` → `src/layouts/shortcodes/*`
- `@/helpers/*` → `src/layouts/helpers/*`

## Content + i18n model

- Collections (`src/content.config.ts`, glob `**/[^_]*.{md,mdx}` — underscore-prefixed files are ignored): `services` (folder name comes from `settings.servicesFolder`; includes the `Capacitaciones`/`Training`/`Formations` category), `sections`, `homepage`. Zod schemas in `src/sections.schema.ts`; base frontmatter (`draft`, `customSlug`, `excludeFromSitemap`, `weight`, `categories`, …) + per-section keys. List pages group entries by `categories[0]`.
- Content path is `src/content/<collection>/<contentDir>/…` where `contentDir` (`english`/`french`) comes from `src/config/language.json` — not the lang code. Keep `en`/`fr` pairs in sync.
- Always query via `getCollectionCTM(collection, lang)` / `getEntryCTM` from `src/lib/contentParser.astro`: filters by `contentDir`, excludes `-index` ids, strips `draft: true` only in `PROD` builds, sorts by `weight`.
- All internal links via `getLocaleUrlCTM(url, lang, prepend?)` / `getEntrySlugCTM` (`src/lib/utils/i18nUtils.ts`); handles `showDefaultLangInUrl`, trailing slash, absolute URLs, `mailto:`/`tel:` passthrough. UI strings via `useTranslations(lang)` + `t("key")` from `src/i18n/<lang>.json` + `src/config/menu.<lang>.json`.
- Routes live under `src/pages/[...lang]/` (`index.astro`, `services/[single].astro`); `404.astro` and `robots.txt.ts` are top-level.

## Gotchas

- `scripts/remove-multilingual.mjs` is destructive (deletes non-default `contentDir` folders, `menu.*` except `menu.en.json`, `src/i18n/*` except `en.json`, prunes `language.json`). Don't run unless asked.
- `scripts/generate-multilingual-content.mjs` / `generate-favicons.mjs` are one-shot generators, not part of build.
- Drafts are visible in `dev` but filtered in `build`; `excludeFromSitemap`/`draft` sitemap cleanup only runs via `npm run build`, not plain `astro build`.
